One line for the make.fun bounty "The 3AM Fridge Text": the smart fridge snitches on the microwave at 3am — it kept a log of the owner's late-night burrito reheats and reads it out loud, because a fridge keeps receipts, not leftovers.

## Run it

```sh
python3 main.py
```

Writes the single-line fridge text to `/output/entry.txt` (and a byte-identical copy to `entry.txt` next to the script).
